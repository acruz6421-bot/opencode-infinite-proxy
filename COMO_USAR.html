⚡ OpenCode Zen Proxy Infinite

Servidor proxy reverso com Auto-Rotação de IP via Cloudflare WARP para uso ilimitado dos modelos gratuitos do OpenCode em qualquer agente (Claude Code, Cline, Roo Code, Cursor, etc.).

1. Pré-requisito: Chave do Cloudflare WARP Gratuito ou Pago

Para que o proxy possa girar o IP automaticamente quando a cota gratuita por IP atingir o limite, é obrigatório informar uma Chave de Licença do Cloudflare WARP (pode ser uma chave da versão Gratuita ou da versão WARP+ Unlimited).

  1. Abra o app 1.1.1.1 no celular (Android/iOS) ou no PC.
  2. Vá em Configurações (Engrenagem) → Conta → Chave (Key).
  3. Copie a chave no formato xxxxxxxx-xxxxxxxx-xxxxxxxx.

2. Como Iniciar (2 Cliques)

  1. Dê dois cliques em INICIAR_PROXY.bat.
  2. Na primeira execução, se o Cloudflare WARP ou o Bun não estiverem instalados, o script fará a instalação automática.
  3. Cole sua chave do WARP quando solicitado e pressione Enter (ela ficará salva em warp-key.txt).
  4. Deixe a janela aberta (pode minimizar). O WARP opera em Modo Proxy Local (porta 40000) e não altera nem desconecta a internet do seu PC.
